# Security

Lectern reads untrusted content (Markdown and HTML from folders you open), so its safeguards are described in [docs/security.md](docs/security.md).

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private vulnerability reporting (the **Security** tab of the repository, then **Report a vulnerability**). Include the steps to reproduce, ideally with a minimal document or folder.

Lectern is maintained by one person: expect an answer within a few days, and a fix as soon as it is understood.

## Supported versions

Only the latest release.
