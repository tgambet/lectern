A document in Lectern's theme

This page is plain HTML with no stylesheet of its own. One line in its head asks Lectern for its design system, so it reads like the rest of the folder, in light and dark.

Opting in

Add the meta tag, and put lc-prose on the body or on an element. 

<meta name="lectern-theme" content="on">
<body class="lc-prose">

Note

Opened outside Lectern, this page is unstyled but still readable: the markup is ordinary HTML. Your own styles, if any, win over the theme.

What you get

Headings, links, lists, Ctrl + K, marks and inline code come from the same tokens as the app.

  • Paper, ink and a single accent
  • Literata for reading, JetBrains Mono for code
  • A dark theme that follows Lectern's toggle
Class Use
lc-prose Reading column and type
lc-lede Opening paragraph
lc-notice Note, warning or danger box

Warning

Scripts mode keeps the page's own look: its policy only allows inline styles.
