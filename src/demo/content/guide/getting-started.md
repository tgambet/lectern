# Getting started

Lectern opens a folder on your computer and shows its documentation. It needs Chrome or Edge, which can read local folders.

## Open a folder

1. Click **Open another folder…** in the header.
2. Pick the folder of a repository, or its `docs/` folder.
3. Lectern lands on the folder's README and lists every document on the left.

Lectern only asks to **read** the folder. It never writes to it.

## Next time

Lectern remembers the folder. When you come back, it opens directly, or asks once for permission with a single click: browsers forget folder access when they restart.

## Install it

Install Lectern as an app (the install icon in the address bar, or **Install app** in the header) to keep it one click away. Once installed, it works fully offline.
