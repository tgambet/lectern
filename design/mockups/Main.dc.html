Architecture

Lectern reads a folder through the browser's File System Access API and renders what it finds. There is no server: every page is produced on this device.

How a document is served

A Service Worker answers requests under a virtual path and reads the file through the stored folder handle, so relative links, images and styles keep working. See the security model for how HTML documents are sandboxed.

ts
const root = await window.showDirectoryPicker({ mode: "read" });
// Lectern never asks for write access

Constraints

RuleWhat it means
