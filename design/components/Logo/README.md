The logo component shows the lectern mark in the app chrome: the mark is inline SVG in `currentColor` (`accent`, so it follows the theme) next to "Lectern" set in `font-serif` 600, as in the mockups.

The consumer provides nothing but the size: the header lockup, or a bare symbol inside another component such as `lc-resume__mark`.

- The logo is a landmark for the eye, not a control: it is not a link in the MVP.
